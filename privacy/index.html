Omen

Privacy policy

October 15, 2026

Omen is a card game you play in a browser or inside a Discord voice channel. This page says what the game stores. It does not cover Discord itself. Discord has its own privacy policy.

On your device

If the browser allows it, Omen saves a few things locally:

  • A seat token in the tab, so you can rejoin the same table if you close the Activity and come back.
  • Settings: the name you typed, volume, whether sound is on, motion, larger text, whether ending a turn asks first, whether the match log starts open, and whether you skipped the practice match.

Omen does not use cookies, advertising, or analytics. This page doesn’t either. Clearing the site data for Omen removes what is saved on your device.

On the server

There is no Omen account.

When you sit at a table, the server keeps that table in a file so the match can continue if the server restarts. The file includes the display name at your seat, a seat token that lets that seat reconnect, the match (including the cards in each hand), and the last 40 chat messages.

People at your table can see your display name, your public stats, and the chat. They cannot see your hand.

An empty lobby is deleted when everyone has left. A table with a match stays in the file after the match ends, until it is removed from the server. That file is not published.

When a match ends, the server also keeps a short note in memory: an internal match id, the table code, who won, whether it was a draw, and the time. That note is gone when the server process stops. It does not include a Discord account.

The game code does not keep a list of IP addresses.

Discord

If you open Omen from Discord, the Activity asks for two permissions: identify and guilds.

identify is used to read your Discord user id, username, and display name. Your display name, or your username if you don’t have one, becomes your name at the table. The server sends the Discord access token back to your browser so the Activity can sign in. Omen does not save the access token or your Discord user id in the table file.

guilds is part of that login. Omen does not read or save the list of servers you belong to.

Inside Discord, the table code comes from the Activity instance, the channel, or the server, so people in the same instance share a table. That code is saved with the live table.

Discord still receives whatever it normally receives when you use an Activity. That stays under Discord’s policy.

What we don’t do

We don’t sell information, and we don’t share it with advertisers. Other players at your table see the game. Discord sees the Activity login. That’s the list.

How long it stays

Settings stay on your device until you clear them. A live table stays on the server until the lobby is empty or the file is removed. If you want a table taken down, ask, and we’ll remove it if we can still find it.

Children

Omen is not for children under 13. You also have to be old enough to use Discord.

Changes

If this policy changes, the date at the top changes with it. The new version replaces this one when it is posted here.
